# Flores Gardening — Garden Journal

## What changed
A new photo-led public website, replacing the Pollen and pastel iterations. The visual language is evergreen ink (#243d2b), clear ivory (#f7f8f3), real garden imagery, straight edges and restrained typography. There are no pink/lilac backgrounds, arched logo containers or coloured promotional cards. The original logo remains in the header and footer.

The headline now explains a customer benefit: More time to enjoy your garden. Four clear routes lead to regular care, pruning and hedges, planting and borders, and one-off resets. The services page expands each route. The existing seasonal guide and postcode checker remain, supported by practical FAQs, a simpler three-step enquiry explanation and matching contact styling.

## Research reviewed
- Green Heart Horticultural Services — https://www.greenhearthort.co.uk/ — useful separation between ongoing care, specialist pruning and planting; clear next steps and questions. Applied the service hierarchy, without importing its rates, credentials or guarantees.
- Land Girls Cardiff — https://www.landgirlscardiff.co.uk/ — relevant local female-run competitor with direct language about maintenance, pruning, planting and clearance. Applied local clarity, without copying its biography, qualifications, reviews or pricing.
- Rich Allan Gardens — https://www.richallangardens.co.uk/ — explains maintenance and planting through customer needs. Applied outcome-focused introductions and concrete lists of included work.
- The Lady Gardener — https://www.theladygardener.co.uk/ — female-led ecological care, practical service language and wildlife positioning. Kept Flores’s approach tangible rather than adding unverified ecological or professional credentials.
- Tom Stuart-Smith Studio — https://www.tomstuartsmith.co.uk/ — reviewed homepage structure and stylesheet; restrained navigation provides a useful reference for a garden-led presentation.
- Arne Maynard — https://arnemaynard.com/gardens/ — reviewed portfolio structure and stylesheet; garden projects take precedence over promotional furniture. Its palette was not adopted.

This is an original layout and copy, informed by the references. It does not use competitors’ code, logos, project photos, testimonials, qualifications or prices.

## Preview
Open DESIGN-PREVIEW.html directly in a browser. The self-contained file covers home, services and contact, plus postcode checks, seasonal tabs and FAQ accordions. Its enquiry form does not send or save data. It uses production page markup with lightweight local interaction equivalents.

## Deployment and verification
Run npm ci, then npm run build. Use the existing Next.js/Vercel setup and Supabase environment variables. No deployment was performed.

Production build passed. Internal page links, section targets, packaged images, preview JavaScript syntax and key text contrast were checked. Browser visual and interaction QA was unavailable in this environment. Live Supabase enquiry submission was not tested.

Server API routes, owner dashboard components, analytics tracking, enquiry validation, schema and service-interest values were retained. Public copy, layout, navigation, styles and service grouping were revised.
